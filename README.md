# 송일초 RPG — 3D 웹게임 업데이트 초안

사진 속 친구의 헤어스타일, 검은 뿔테 안경, 줄무늬 상의, 검은 바지와 운동화 특징을 참고한 오리지널 저폴리 3D 캐릭터가 등장하는 브라우저 RPG입니다. 사진 원본은 프로젝트에 포함하지 않았습니다.

## 실행하기

- `index.html`을 웹 서버로 열어 실행합니다.
- VS Code에서는 Live Server를 사용하거나, 프로젝트 폴더에서 `python -m http.server 8000`을 실행한 뒤 `http://localhost:8000`으로 접속합니다.
- Three.js를 CDN에서 가져오기 때문에 인터넷 연결이 필요합니다.

## 조작

| 키 | 기능 |
|---|---|
| W A S D | 이동 |
| SPACE | 점프 |
| SPACE 공중에서 다시 누르기 | 더블 점프 (총 2단 점프) |
| 마우스 왼쪽 클릭 | 검 휘두르기 (10 데미지) |
| E | 경비실 아저씨와 대화 / 대화 넘기기 |

## 이번 업데이트

- 카메라를 축구 중계 화면처럼 중앙 뒤쪽의 높은 위치에서 내려다보는 브로드캐스트 시점으로 변경하고, 렌즈 시야각을 좁혀 재석이가 화면에서 더 크게 보이게 조정했습니다.
- 등굣길을 이전보다 넓고 길게 확장하고 나무, 울타리, 꽃길, 학교 정문을 추가했습니다.
- 경비실 건물과 경비실 아저씨 NPC를 추가했습니다. 가까이 다가가면 E 키로 대화할 수 있습니다.
- 더블 점프를 추가하고, 두 번째 점프 순간 발밑에서 원형 빛과 스파크가 퍼지는 이펙트를 넣었습니다.
- 문제집 표지를 학년·학기·교재 제목·핵심 단원·개념/유형/단원 평가가 보이는 오리지널 학습서 스타일로 세밀하게 만들었습니다. 실제 특정 출판사의 표지·내지·문항을 그대로 복제하지는 않았습니다.
- 재석이의 모자 없는 곱슬 머리, 일반 크기의 눈, 검은 뿔테 안경과 얼굴·옷 디테일을 보강했습니다. 첫 화면에서는 얼굴을 볼 수 있도록 카메라 쪽을 향합니다.
- 적의 투사체는 책이나 종이판이 아니라 투명 배경의 가분수 숫자 자체가 빛나는 구체와 함께 날아갑니다. 분수의 계산값이 실제 피해량이며, 예를 들어 18/3 투사체는 정확히 6 HP를 깎습니다.

## 전투 수치

| 항목 | 값 |
|---|---:|
| 재석이 체력 | 100 |
| 검 공격력 | 10 |
| 첫 번째 적 체력 | 50 |
| 문제집 공격력 | 5~10 (가분수 값으로 표시) |
| 문제집 공격 주기 | 0.67초 |

예시 투사체는 `18/3`, `24/4`, `21/3`처럼 표시되며, 분자 ÷ 분모의 실제 값만큼 플레이어 체력이 감소합니다.

## GitHub + Render 배포

1. 압축을 풀고 안에 있는 `index.html`, `game.js`, `style.css`, `README.md` 파일을 GitHub 저장소 최상위에 덮어 올립니다.
2. `render.yaml`도 포함되어 있으며, Render에서는 **Static Site**를 사용합니다.
3. Root Directory는 비워 두고 Publish Directory는 `.`로 설정합니다. Build Command는 비워 두어도 됩니다.
4. GitHub에 커밋하면 Render가 자동 배포합니다.

이 초안은 정적 웹게임입니다. Neon, 회원가입, 로그인, 계정 동기화 및 서버 기능은 포함하지 않습니다.
