# 송일초 RPG — 3D 웹게임 초안

사진 속 친구의 특징을 참고해 만든 **저작권 없는 오리지널 저폴리 3D 캐릭터**와 첫 번째 문제집 적이 등장하는 브라우저 RPG 프로토타입입니다. 업로드한 사진 파일 자체는 프로젝트에 넣지 않았습니다.

## 실행하기

가장 간단한 방법은 `index.html`을 바로 여는 것이지만, 브라우저 설정에 따라 ES 모듈을 차단할 수 있습니다. 아래처럼 로컬 서버를 실행하는 방법을 권장합니다.

### VS Code 사용

1. 압축을 풀고 폴더를 VS Code로 엽니다.
2. `Live Server` 확장 프로그램을 설치합니다.
3. `index.html`에서 **Open with Live Server**를 누릅니다.

### Python 사용

프로젝트 폴더에서 다음 명령을 실행합니다.

```bash
python -m http.server 8000
```

브라우저에서 `http://localhost:8000`을 엽니다.

## 게임 조작

- `W A S D`: 이동
- `SPACE`: 점프
- 마우스 왼쪽 클릭: 검 휘두르기
- 문제집 가까이에서 적을 바라보고 클릭하면 공격이 적중합니다.

## 현재 구현된 규칙

| 항목 | 설정 |
|---|---:|
| 재석이 체력 | 100 |
| 기본 검 공격력 | 10 |
| 첫 번째 적 체력 | 50 |
| 문제집 공격력 | 5~10 랜덤 |
| 문제집 공격 주기 | 0.67초 |
| 적 투사체 | 공격력과 같은 값이 되도록 분자·분모를 2배로 표현한 가분수 종이 투사체 |

문제집은 5번의 검 공격을 맞으면 쓰러집니다. 현재는 단일 적 전투를 테스트하는 초안입니다.

## 캐릭터와 적 디자인

- 플레이어: 검은 둥근 뿔테 안경, 풍성하고 약간 웨이브가 있는 검은 앞머리, 어두운 회색·청록 계열 줄무늬 긴팔 상의, 검은 바지, 파란 양말, 흰색 운동화의 특징을 도형으로 표현했습니다.
- 막대기는 모델링하지 않았으며, 기본 검을 들고 있습니다.
- 캐릭터는 약 1.4 단위 높이로 작게 표현했습니다.
- 적: 실제 출판물의 표지나 내지를 복사하지 않고, **초등 수학 6-1 기본**이라는 가상의 표지로 새로 디자인했습니다. 실제 교재 시리즈의 학년·학기별 구성과 기본/응용 학습서라는 분류에서 아이디어만 얻었습니다.

참고한 교재 안내: EBS 초등 교재 안내 자료의 만점왕 수학 시리즈 및 초등 학기별 교재 구성. 아래 링크는 교재 시리즈와 학습서 분류를 확인하기 위한 참고 자료이며, 게임 표지·문항을 복제한 것은 아닙니다.

## GitHub + Render 배포

1. GitHub에서 새 저장소를 만듭니다.
2. 압축을 푼 **폴더 안의 파일들**(`index.html`, `game.js`, `style.css`, `README.md`, `render.yaml`)을 저장소 최상위(root)에 올립니다.
3. Render에서 **New + → Static Site**를 선택하고 GitHub 저장소를 연결합니다.
4. Build Command는 비워 두거나 `echo "No build step"`, Publish Directory는 `.` 로 설정합니다.
5. Deploy를 누릅니다.

이 버전은 Three.js를 CDN에서 불러오는 정적 웹사이트입니다. 따라서 인터넷 연결이 필요하고, Neon DB나 회원가입·로그인·계정 동기화 기능은 포함되어 있지 않습니다.
